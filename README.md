# Ravvo — управление Telegram-группами

Все функции работают прямо в Telegram. Веб-сайт и регистрация не используются.

Интерфейс оформлен в едином стиле Ravvo. Бот использует собственные WebP-стикеры для приветствия, подтверждений и раздела модерации.

## Быстрый запуск на macOS

```bash
cd ~/Downloads/sentinel-telegram-suite
cp .env.example .env
open -e .env
npm install --cache ./npm-cache
npm run setup
npm run dev
```

## Подключение

1. Создайте бота через @BotFather.
2. Выполните `/setprivacy` → `Disable`.
3. Добавьте бота в группу и назначьте администратором.
4. Разрешите удалять сообщения, банить, ограничивать участников и закреплять сообщения.
5. Отправьте `/start` или `/menu`.

Любой пользователь может открыть `/start` и нажать «Добавить Ravvo в группу». Telegram покажет только те группы, где пользователь имеет право добавлять администраторов. После подключения Ravvo отправит инструкцию по первоначальной настройке. Администраторы управляют только своими группами; `ADMIN_TELEGRAM_ID` не ограничивает публичное подключение.

## Кнопочное меню

- главное меню состоит из трёх разделов: «Заказать», «Модерация» и «Добавить бота в группу»;
- заказы: Discord-сервер, Java-плагин, Python-бот и информационный сайт;
- создание публикаций с несколькими URL-кнопками;
- изменение и публикация правил;
- собственные приветствие и прощание с переменными `{user}` и `{group}`;
- кнопочная панель защиты: CAPTCHA, ссылки, стоп-слова, антифлуд, капс, пересылки и медиа;
- разрешённые домены, лимит варнов и выбор автоматического наказания;
- периодические напоминания;
- справочник модерации;
- публичная форма заказа Java-плагина;
- принятие или отклонение заявки владельцем.

Все заявки отправляются только владельцу из `ADMIN_TELEGRAM_ID`. Заказ Java-плагина собирает идею, версию Minecraft, ядро, Java и бюджет. Остальные направления собирают техническое задание и бюджет. Владельцу приходит имя, username, Telegram ID и вся информация заказа. После принятия или отказа владелец может написать причину либо пропустить её, а бот уведомит покупателя.

## Команды

- `/menu` — главное меню;
- `/order` — заказ Java-плагина;
- `/ban`, `/mute`, `/unmute`, `/kick`, `/delete`;
- `/unban`, `/warn`, `/unwarn`, `/warns`, `/report`;
- `/purge`, `/pin`, `/pinned`, `/unpinall`;
- `/silence`, `/unsilence`, `/send`;
- `/info`, `/staff`, `/me`, `/chatid`, `/link`, `/reload`;
- `/role give/remove`;
- `/rules`, `/setrules`, `/announce`.

Временные наказания и напоминания хранятся в SQLite и восстанавливаются после перезапуска.

Стоп-слова настраиваются через запятую. При совпадении Ravvo удаляет сообщение, записывает предупреждение и после достижения лимита применяет выбранное наказание: мут, исключение или блокировку.

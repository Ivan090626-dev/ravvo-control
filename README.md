# Ravvo — управление Telegram-группами

Все функции работают прямо в Telegram. Веб-сайт и регистрация не используются.

Интерфейс оформлен в едином стиле Ravvo. Бот использует собственные WebP-стикеры для приветствия, подтверждений и раздела модерации.

## Быстрый запуск на macOS

```bash
cd ~/Downloads/sentinel-telegram-suite
cp .env.example .env
open -e .env
npm install --cache ./npm-cache
npm run setup
npm run dev
```

## Подключение

1. Создайте бота через @BotFather.
2. Выполните `/setprivacy` → `Disable`.
3. Добавьте бота в группу и назначьте администратором.
4. Разрешите удалять сообщения, банить, ограничивать участников и закреплять сообщения.
5. Отправьте `/start` или `/menu`.

## Кнопочное меню

- создание публикаций с несколькими URL-кнопками;
- изменение и публикация правил;
- собственные приветствие и прощание с переменными `{user}` и `{group}`;
- периодические напоминания;
- справочник модерации;
- публичная форма заказа Java-плагина;
- принятие или отклонение заявки владельцем.

Заказ плагина собирает идею, версию Minecraft, ядро, Java и бюджет. Владельцу приходит имя, username, Telegram ID и вся информация заказа. После принятия или отказа владелец может написать причину либо пропустить её, а бот уведомит покупателя.

## Команды

- `/menu` — главное меню;
- `/order` — заказ Java-плагина;
- `/ban`, `/mute`, `/unmute`, `/kick`, `/delete`;
- `/unban`, `/warn`, `/unwarn`, `/warns`, `/report`;
- `/purge`, `/pin`, `/pinned`, `/unpinall`;
- `/silence`, `/unsilence`, `/send`;
- `/info`, `/staff`, `/me`, `/chatid`, `/link`, `/reload`;
- `/role give/remove`;
- `/rules`, `/setrules`, `/announce`.

Временные наказания и напоминания хранятся в SQLite и восстанавливаются после перезапуска.
